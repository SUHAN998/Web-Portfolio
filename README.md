# Clear Orbit — Su Han Portfolio Prototype

구성:
- `index.html`
- `styles.css`
- `app.js`
- `assets/` — 제공된 3번 시안에서 **프로젝트 카드의 썸네일 영역만** 분리한 이미지

## 실행
가장 간단한 방법:
1. 폴더를 VS Code에서 엽니다.
2. `index.html`을 Live Server로 실행합니다.

또는 브라우저에서 `index.html`을 직접 열어도 기본 기능은 동작합니다.

## 구현된 요구사항
- 첫 실행은 Intro 화면
- Intro 중앙 SH 별자리 로고가 상단으로 이동하며 Explore로 전환
- 프로젝트 / Profile / Skill / Contact 노드 순차 등장
- 우측 상단 View Option 순차 등장
- Explore ↔ List 전환
- List 전환 시 별 Fade out → 카드가 좌측 상단 기준으로 빠르게 순차 등장
- Explore / List 모두 프로젝트 클릭 시 modal
- modal은 선택 항목 위치에서 앞으로 날아오는 형태
- 배경은 이미지가 아니라 Canvas particle
- 1440×1024 / 1440×1290 디자인 비율을 기준으로 `%` 좌표 사용
- 좌우 공통 padding은 `%/vw` 기반
- 모바일/좁은 화면에서 요소가 지나치게 작아지지 않도록 clamp/min-size 적용

## 프로젝트 상세 내용
현재 모달에는 프로젝트명/종류/짧은 설명이 들어 있습니다.
실제 Case Study가 준비되면 `app.js`의 `PROJECTS` 객체만 수정하면 됩니다.

## V14 — 크기 반응형 Intro Stardust
- 입자 크기는 V13의 미세한 0.4px~1.4px 유지
- 입자 개수와 생성 범위를 고정값이 아닌 실제 DOM 렌더링 크기로 자동 계산
- 큰 폰트일수록 글자 하나에 모이는 입자가 많아지고 생성 범위도 넓어짐
- 작은 폰트는 상대적으로 적고 좁은 범위에서 모임
- 한글/넓은 글리프는 width/area 보정을 받아 조금 더 많은 입자가 생성됨
- SH 로고는 실제 width/height에 따라 sweep column, row, 입자 수, spread가 자동 증가/감소
- clamp/min/max를 적용해 초대형 화면에서도 과도하게 무거워지지 않도록 상한 설정
- 반응형 CSS로 글자/로고 크기가 바뀌면 별가루 효과도 자동으로 비례 변경

## V36 — 시안 기반 최종 정리
- 모달 바깥 배경: 검정 오버레이 20% + 16px 블러, 열림/닫힘 1.1초 전환

- List 카드와 헤더 간격 확대 + 하단 3개 Profile/Skill/Contact 가로 버튼 추가

- 프로젝트/Profile/Skill/Contact 데스크톱 모달 외곽 크기 통일 및 모바일 공통 반응형 크기
- 긴 프로젝트 제목은 한 줄 유지, 폭이 모자라면 문자 크기/자간 자동 축소

- 카메라 이동 거리 -1.75~+0.85 (기존 -0.54~+0.76보다 약 2배 깊이), 노드별 Z 레이어 분산 확대
- 먼 프로젝트 제목은 약 30% 흐려졌다 밝아지는 반복 호흡 효과
- Contact 모달 열면 아이콘은 중심→왼쪽 이동, 텍스트는 왼쪽→오른쪽 Fade In, 이후 전화번호 한 번 점멸과 1.2배 확대
- 나머지 기존 V35 기능 유지

## V38 — 프로젝트 모달 이미지/설명 영역 비율 2:1

## V40 — Contact 모달 등장 순서와 전화번호 강조 크기 보정
- 기준 버전: V39. Contact 외의 코드/디자인/에셋은 유지
- 모달 창의 1,240ms 등장 애니메이션이 완전히 끝날 때까지 아이콘 및 연락처 텍스트 고정
- 오픈 완료 후 두 아이콘은 실제 연락처 영역의 중앙에 세로로 정렬된 위치에서 왼쪽의 기존 아이콘 열로 1초 이동
- 이메일 및 전화번호 텍스트는 같은 타이밍에 왼쪽에서 오른쪽으로 1초 동안 reveal/fade-in
- 텍스트 등장 완료 뒤 전화번호 확대 비율을 1.30배에서 1.10배로 축소 (닫기 전까지 유지)
- 기존 한 번의 5초 은은한 glimmer 유지, 재오픈하면 초기 상태부터 반복
- 모달이 완성되기 전에 닫으면 관련 애니메이션이 실행되지 않도록 보호
